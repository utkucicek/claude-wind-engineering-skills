# Reference — approach flow in the wind tunnel (ASCE/SEI 49-21)

Source: ASCE/SEI 49-21, Chapters 1, 2 and commentary C2. Page = PDF page order (not the printed page number).

Type column:
- **MANDATORY** — "shall" in the standard text.
- **MANDATORY (permitted)** — "shall be permitted" in the standard text (a permitted option).
- **RECOMMENDED** — "should" / "recommended". In this standard almost all "should" statements are in the commentary; these are marked "COMMENTARY (recommendation)".
- **COMMENTARY** — commentary (C chapters); not binding.
