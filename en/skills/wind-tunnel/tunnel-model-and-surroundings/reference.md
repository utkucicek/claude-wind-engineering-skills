# Reference — tunnel model and its surroundings (ASCE/SEI 49-21)

Source: ASCE/SEI 49-21, §1.2, §1.4, §2.2, §2.4, §2.6, §3.2, §8.1 and the related commentary sections. Page = PDF page order.

Type column: **MANDATORY** = "shall" in the standard text; **MANDATORY (permitted)** = "shall be permitted"; **COMMENTARY** = commentary (not binding); **COMMENTARY (recommendation)** = a "should / recommended" statement in the commentary. In the body of the standard there is no separate recommendation written with "should" on these topics.

## Not found in the text

- A **mandatory** minimum radius for the proximity model (in terms of H or in meters): none. The ~240 m in the commentary is only a description of common practice.
- A specific formula or method for blockage correction: none.
- An upper blockage limit permitted above 5%: none.
- A separate numerical Reynolds threshold for structures of circular cross section: none (only the general lower limit of 11 000 and the qualitative discussion in the commentary).
- A number for the wind direction increment in the body of the standard: none (10° is only in the commentary).
- A permitted numerical range for the model scale: none (the commentary has only typical values: tall building 1:300–1:500, general 1:20–1:800, topography 1:500–1:5 000, product tests 1:50 or larger, bridge section model 1:10–1:100, tall building aeroelastic 1:200–1:600, small structures 1:1–1:20).
